# Active Tasks

## How to Use This File

This file tracks **active tasks only**. When tasks are completed, they should be cleared from this file (completed work is tracked via git commits).

### Guidelines

1. **Add tasks** when planning new features or bug fixes
2. **Check off tasks** using markdown checkboxes as you complete them: `- [x]`
3. **Clear completed tasks** regularly (move them out of this file)
4. **Keep it focused** on current sprint/iteration work
5. **Use descriptive titles** so context is clear
6. **Group related tasks** under headings

### Task Format

```markdown
## Feature/Epic Name

- [ ] Task description
- [ ] Another task
  - [ ] Sub-task (indent for hierarchy)
  - [ ] Another sub-task
- [ ] Final task
```
